# ============================================================================
# PARAMETER REFERENCE
# ============================================================================
# interval: milliseconds between fixes/measurements (required for most tests)
# timeout: seconds to wait for result before declaring FAIL (optional, default varies)
# duration: seconds to hold the session open collecting every fix/epoch, for
#           TC8_POSITION_CLIENT_REF/TC9_MEAS_AND_CLK_CLIENT_REF/TC10_POSITION_MEAS_AND_CLK_CLIENT_REF
#           only (optional; default unset = one-shot, stop after the first one)
# iterations: cycle count for TC2/TC3 (optional, default 5)
# sessionMode: 1=NORMAL, 2=SWIM, 3=STAMINA (optional, default 1)
# pdrMode: 1=CASUAL, 2=FITNESS (optional, default 1)
# maxMeasCount: max measurement reports to receive (optional, default 0=unlimited)
#
# Breach type values:
#   1  = ENTER
#   2  = EXIT
#   5  = ENTER + DWELL_IN
#   10 = EXIT + DWELL_OUT
#
# Responsiveness: milliseconds (lower = more responsive, higher power)
# Dwell time: seconds
# Latitude/Longitude: decimal degrees
# Radius: meters
# id (optional 7th geofence field): driver-assigned id, REQUIRED for
#   TC12-14_REMOVE/MODIFY/PAUSE/RESUME_CLIENT_REF (use the value a prior
#   TC11_GEOFENCE_ADD_CLIENT_REF's ack returned). Not used by
#   TC11_GEOFENCE_ADD_CLIENT_REF or QSH_LOC_TEST_GEOFENCE.
